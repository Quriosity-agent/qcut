# 单张照片：腰腹、臀型、腿型与身体皮肤

新增九项只在 **CPU / ONNX 图片版**启用，连同原十二项共二十一项，按部位分组。原始 `catalog.json`、Metal 默认参数契约及固定的 107 个引擎文件保持不变；已有美颜不参与本条流水线。

| 项目 | 参数 | 范围 | 实际作用 |
| --- | --- | --- | --- |
| 独立收腹 | `Abdomen` | 0–100 | 在肩髋之间局部收拢腹部轮廓；避让可见的手与前臂 |
| 提臀 | `ButtLift` | 0–100 | 向上调整臀部附近的二维轮廓 |
| 臀型宽度 | `ButtShape` | -50–50 | 调整下胯至上大腿的连续轮廓，区别于原胯宽 |
| 腿型拉直 | `LegStraighten` | 0–100 | 对近正立双腿作局部膝位对齐；固定髋、踝 |
| 脚踝粗细 | `AnkleWidth` | -50–50 | 局部收细／加宽下小腿至踝上区域，保留鞋部 |
| 身体明暗 | `BodySkinTone` | -50–50 | 在可靠皮肤选区内加深／提亮 |
| 身体冷暖 | `BodySkinWarmth` | -50–50 | 在同一选区内偏冷／偏暖 |
| 身体磨皮 | `BodySkinSmooth` | 0–100 | 柔化细碎纹理，保留较大明暗结构 |
| 淡化小瑕疵 | `BodyBlemish` | 0–100 | 柔化小范围暗色残差，不生成新皮肤 |

数值是算法强度，不代表厘米、围度、身高变化百分比或医学体态矫正。臀部处理是二维照片修形，不补画侧面体积；正面照不能证明侧面臀部投影得到重建。

## 使用

在本版目录启动新的 CPU 服务，不切换或覆盖旧 Mac 应用目录：

```sh
BODY_RENDER_BACKEND=cpu body/.venv/bin/python -B body/server.py --port 5284
```

Windows 使用对应虚拟环境的 `Scripts/python.exe`，先设置 `BODY_RENDER_BACKEND=cpu`。安装步骤仍见 [多平台说明](PORTABLE.md)。模型数量不变，不需要重新训练或导出网络。

导入照片、修改滑杆、点击应用，再用半图擦拭或完整结果确认后下载 PNG。参数更改会立即使上次下载失效。归零包含九项新参数，每次都从保存的原图重新处理。

## 组合与保护

皮肤处理在原图坐标中先执行，再与比例、局部修形共用最终照片采样。原十二项请求继续走原路径；新参数全为零时，不重采样原十二项的网格。新部位不可用时，旧项仍可执行；没有新几何或手动笔画时保留旧网格。

几何扩展使用实际检测的关节，并分别记录作用范围、是否移动、网格安全缩放及未应用原因。多个人物、关节缺失、交叉或明显弯膝会限制自动执行；不推测被裁掉或遮住的身体。收腹避让手臂后，可能只剩很小的可调整区域，不把避让区当成已重建的腹部。

身体皮肤采用**人脸参考肤色、人体关节支持和人物蒙版共同约束的自适应选区**，没有新增语义皮肤分割模型。头脸排除，选区外像素逐字节保留，颜色与纹理共享相同选区。深阴影、肤色相近的织物、复杂彩光及遮挡仍可能导致漏选或误选，必须检查完整照片。人脸参考不可靠时跳过皮肤项目；不能把人物蒙版直接当作皮肤。

磨皮和瑕疵淡化不会重建大面积疤痕、纹身或衣物下的皮肤。已有商业写真通常已修饰，变化小也可能是原图缺少对应瑕疵，不能据此声称任意祛斑能力。

## 提臀、腿型与小暗点的增强

提臀采用髋线固定、下臀至上大腿连续过渡的提升范围，保留可见手臂及膝部。不同姿势的最大位移不必都增大，重点是轮廓和裤缝连贯移动，避免只挤动狭窄区域。

腿型仍以检测到的髋点与踝点连线为目标，让膝部的内部与外轮廓共同跟随。满档不会让膝点越过目标轴；髋部上方和鞋部留有固定网格缓冲。原图已接近直立时，变化仍可能只有几个像素；跨步、明显屈膝、交叉及关节缺失不会因为增强而被强行执行。

瑕疵淡化改为多尺度小暗点检测和周围皮肤的局部修复，普通皮肤纹理不作为整片模糊目标。仅 `BodyBlemish` 可补齐被可靠皮肤完整包围的极小暗点孔，仍受人物、头脸及透明度边界限制；小痣也可能淡化。肤色、冷暖和磨皮继续使用原皮肤选区。

回执在 `parts.BodyBlemish.blemishDetection` 中记录候选数、接受的小点数、基础与实际选区哈希、`additionalSupportPixels` 和修复支持哈希。保护区域按各项目实际支持范围计算，不能把新增小孔修复描述为“旧皮肤选区外完全不变”。

增强验证沿用同六张 VSX 输入，使用每张 24 次请求覆盖三项中档／满档、受保护结果、组合、处理前后归零，以及未改动项目的 PNG 回归。原图、每次请求、实际下载 PNG、回执及同坐标左右对比均保留；归零或不适用不计为美体成功。

背景保护继续保留远离人物轮廓的背景。紧贴人物、衣物及露出的背景仍可能随轮廓改变；本版不补画背景。满档主要用于检查极值，日常使用请逐项检查邻近部位和纹理。

## 侧面与背面提臀定位

CPU 图片版新增「侧面／背面提臀定位」。先选择臀部朝画面左侧或右侧突出的侧面，或背面；在原图依次标记臀峰和臀下缘，侧面一组、背面左右两组，也可输入原图宽高百分比坐标。点击「使用这组定位」后，再调原有 `ButtLift` 滑杆并应用。点位草稿不改变上次保存的设置；更改点位需要重新保存，保存会使旧结果和下载失效。换图、全部归零会清除定位。

这一模式不依赖双髋分离或膝点可见，使用的是人工选择的衣物可见轮廓，不是自动检测到的臀部解剖点。没有选择定位时，保留原有关节驱动的二维局部提升。原 Mac/Metal 契约不接受新定位字段。

`edits.buttocks` 是可选对象，坐标基于原图左上角、归一化到 0..1：

```json
{"view":"side-left","anchors":[{"peak":[0.435,0.476],"fold":[0.465,0.523]}]}
```

`side-left` 指臀部朝画面左侧突出，`side-right` 相反；`rear` 需要两组不交叉的左右点位。新模式围绕臀峰与下臀轮廓作不同幅度的局部提升，侧面可微调后侧投影；不生成三维体积、隐藏部位或新背景。点位间距必须足够大，作用区上方及下方必须留有过渡空间；轻度裁切可缩短下方过渡并固定画布边缘，贴边或过小的区域会拒绝处理。标记范围内的手、头发、衣物及遮挡也会随形变移动，不能用人工定位冒充自动遮挡重建。

回执 `parts.ButtLift` 显式记录 `anchorSource: "user-supplied-manual-contour"`、`contourLandmarksDetected: false`、原始点位、请求目标、作用范围、裁切过渡及最终组合安全系数。请求目标是连续形变场的目标，不等于实际采样后像素或自动识别结果。每次仍从原图采样一次，并与背景保护使用相同网格。

预览新增「原图／结果闪切」，仅在本次真实结果有效时启用；改参数或点位会停止旧结果闪切。左右半图与 PNG 导出沿用同一实际结果。

## 自动定位与手动校正

新的 CPU 图片界面导入照片时会执行一次零强度分析，结合已有 ONNX 人体关节、人物蒙版和可见轮廓／衣物下缘估计臀部点位。识别通过后，可直接调整「提臀」并应用，无需先手动标点；提臀渲染会在同一原图上重新计算点位。标记来自几何与图像证据规则，不是新训练的臀部解剖关键点网络，显示的置信度是启发式证据评分，不代表经过标注数据校准的准确率。

导入响应 `buttocksDetection` 包含是否可用、归一化点位、证据评分、未通过原因、方法版本以及原图 RGBA SHA。自动请求只增加 `edits.autoButtocks: true`，不从客户端提交自动点位或检测报告。点位与原图不匹配、伪造的自动检测字段以及非布尔开关会被拒绝或降级为待校正；导入分析失败仍保留原图。自动点位不可用时，本次提臀保留原图，可在工具中校正后应用。其他已选部位仍按各自的判定处理。

```json
{"photoId":"导入返回的编号","values":{"ButtLift":70},"edits":{"backgroundProtection":true,"strokes":[],"autoButtocks":true}}
```

可展开「提臀定位与校正」，选中某个点，修改原图坐标后更新该点，也可重新标记。保存后 `edits.buttocks` 手动点位优先，回执保留手动来源；「恢复自动定位」清除手动覆盖并使旧结果和下载失效。全部归零保留本照片的自动模式并恢复自动点位，更换照片会替换检测结果。

`parts.ButtLift.anchorSource` 区分 `automatic-pose-silhouette-contour` 和 `user-supplied-manual-contour`，自动路径记录 `contourLandmarksDetected` 及完整 `automaticDetection`；两者均不表示已测得真实解剖点。零强度 HTTP 输出逐字节使用原图，回执可以复用原图身份已绑定的导入分析，并标记 `automaticDetectionFromImport: true`。

当前验证集 13 张照片中，浅紫侧面和蓝色背面通过自动应用；其余因正面、遮挡、裁切、关节缺失或轮廓不清转手动，包括两张冻结后的留出照片。蓝色背面一侧的下缘较弱，使用共享可见转折作估计，仍需目视检查。该覆盖率不代表任意侧面或背面都能自动定位。已有接口不发送新开关时保留原路径；原 Mac/Metal 版及美颜流程不使用自动定位。

## 验证

六张既有 VSX 写真保持原始文件及来源记录，逐项运行正负极值、中档、组合、归零和旧项回归。半图直接来自同尺寸原图与实际 PNG；不可用、部分应用和实际成功分别计数。图像身份、参数回显、下载一致性、保护区域和目视自然度是不同检查。

```sh

```

测试和开发命令也应禁止生成字节码。固定引擎目录严格核验文件清单，额外的缓存文件会导致安装检查拒绝，不应放宽该校验。
