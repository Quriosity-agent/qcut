## 1. 数量口径

第一阶段有 5 个已验证网络资产、4 个 `.pt`。第二阶段新增旧分镜两个网络、QCut 的 TFLite 人物分割、
降噪和人脸拟合子网，累计 **10 个通过原生对照的网络资产、8 个独立模型包**；新旧分镜各将两个网络合为一包。
其中两个新分镜网络沿用已有原生 trace 回归，不冒称本次重新执行了原生管线。

私有 runtime 清单仍是 69 条记录、64 个唯一资产；TFLite 是这个清单之外的第 1 个源资产。
旧分镜两个资产、降噪和人脸拟合从未支持升级为通过，因此私有清单尚未通过的资产从 59 降为 55。
这 55 个包括 54 个未支持资产和 1 个数值失败候选，含脚本、数据和未知封装，并非 55 个已确认神经网络。
不得把这份包含旧版本的分子除以生产盘点的模型家族数计算完成率。

## 2. 可复用的规模化路径

四个并行方向分别负责旧分镜、GRU 抠像、容器/计算图、TFLite；共享入口和汇总由主任务统一维护。

```text
清单大小/SHA 校验 -> 按内容去重 -> 容器边界校验
  -> 图声明恢复 -> 算子/形状/权重布局恢复
  -> PyTorch 候选 -> state_dict 和 forward 回读
  -> 固定容差原生对照 -> 真实帧/显式状态/reset
  -> 单独的产品接入和编辑器 E2E
```

本阶段恢复了 **30/30 个 ByteNN 子容器的明文图**，声明输入数、层数和行结构均通过校验。
同一个资产可以含多个子网或不同后端，因此不是新增 30 个模型。
GRU 图与四份原生运行时抓图逐字节一致，证明图来源；其数值对照仍然失败，两件事必须分开。

64 个去重资产的容器分类为：27 个含可识别神经图容器、9 个脚本与小数据、
4 个音频不透明容器、15 个结构可识别但载荷未解释、9 个未知二进制/数据。
未知不等于非神经，脚本也可能加载外部神经模型。
详见 [容器报告](CONTAINER-FORMATS.zh-CN.md)。

## 3. 已完成模型的关键差异

### 旧分镜

旧版是 128x128 输入、11 帧窗口、256 维 embedding；新版是 96x96、7 帧、128 维。
旧头的相似度分组是交错通道，新版是连续通道。直接共用新头语义曾导致约 0.0158 的概率误差。
修正后主干最大误差 2.09e-7，预测概率 4.42e-7，相似度中间图 1.08e-6。
不能因为算子名称相似就复用旧/新模型偏移与窗口。
详见 [旧分镜](legacy-shots.zh-CN.md)。

### TFLite 人物分割

恢复 QCut 仓库实际使用的模型，不以另一份公开网络代替。
输入 NHWC `[1,256,256,3]`，按模型 metadata 使用 `(RGB - 127.5) / 127.5`。
输出 NHWC `[1,256,256,6]` 为 **logits**；图外 softmax、合并非背景类、时间平滑和羽化仍属于产品后处理。
14 组输出最大绝对误差 8.8811e-5，固定 `atol=rtol=1e-4`；175/175 个中间算子通过。
PyTorch 推理不需要 TensorFlow 或 MediaPipe；只有导出/原生 oracle 使用隔离的 TensorFlow 环境。
详见 [TFLite](tflite-person-segmentation.zh-CN.md)。

### 降噪与人脸拟合

降噪图有 15 个卷积、4 个 BILINEAR 上采样、5 个残差加法和 1 个拼接，共 62,779 参数。
原始形状三路 `[1,3,1088,1920]` 输入均真实执行，3 组原生对照最大误差 1.0133e-6。
64x64 派生图另记为 `limited-derived-shape-parity-passed`，不冒充原始尺寸结果，不重复计数。
原生输入也经 Extract 回读验证，防止 API 返回成功却只复制了部分输入。
详见 [降噪](denoise_notes.zh-CN.md)。

人脸拟合包包含一个 212->512->512->442 全连接网络，末尾 Sigmoid 乘标量。
11 组输入全部通过 `atol=1e-4, rtol=1e-4`，最大绝对误差约 3.2044e-4。
本适配器调用 `np.allclose(native, pytorch)`，允许误差为 `atol + rtol * abs(pytorch)`，不能误写为最大绝对误差小于 1e-4。
输入 212 维特征的产品归一化、输出 442 维的具体几何解释未证明，不能当作完整人脸拟合 E2E。
初始盘点 A04 应升级为“含神经子网的混合算法包”；核心依赖中的神经家族分类由保守 15 项修正为 16 项，
核心模型/算法包仍是 20 项。这不增加当前生产执行验证数。
原生对照显式强制 CPU 并记录 `forward_type=0`；命名空间叫 `bytenn_cpu` 不代表默认一定不用 GPU。
本结论不覆盖默认 GPU/FP16 路径，不能据此把另一条 GRU 候选的失败改成通过。
默认 GPU 对照实际失败（最大绝对误差约 0.2361），不是仅仅未测试。
原生入口、后端选择和保留集详见 [人脸拟合对照](facefitting-parity.zh-CN.md)。

### 三类 Espresso 真实帧补测

两段本机人物画面参考片，每片解码 24 帧，每模型各 48 次，共 **144 次新原生比较**。
素材含人物及校准画面，不将文件名当作真人实拍证明；没有人工分割或关键点 ground truth。

| 模型 | face 参考片最大误差 | body 参考片最大误差 |
| --- | ---: | ---: |
| 骨骼 | 1.1772e-5 | 1.0401e-5 |
| 皮肤分割 | 1.4231e-6 | 3.4422e-6 |
| 视频对象分割 | 1.1266e-5 | 1.0908e-5 |

视频对象分割分别反馈原生与 PyTorch 自己的 `prev_mask` 和 `prev_img`，不是两边共用 oracle 状态；
每段中途 reset 后继续通过。输入颜色与归一化明确记录，但并未验证全部产品前后处理。
原生使用 CoreML CPU。同输入对照不能代表 Metal、WASM、MPS 或其他平台数值一致。

## 4. 未通过项与下一关

GRU 抠像恢复了 194 个算子、4 个输入、4 个输出、1,787,410 个参数。
候选通过序列化回读，但三组同张量原生对照总体失败：
概率最大误差约 0.0001814，循环状态最大误差约 0.0049550。
已确认本图 LINEAR 上采样使用 half-pixel 零边界，不能用默认边缘复制；修正后仍未达标。
保留 `1e-4` 容差，不通过放宽阈值或只比较 mask 掩盖状态偏差。
下一关是循环单元之前逐层定位，再验证连续反馈、reset、seek。
详见 [GRU 候选和失败证据](matting_route.zh-CN.md)。

小型人脸拟合和降噪已完成本轮模型级对照；下一批优先跟踪子网，再做较大的 OCR、补帧图。
所有新格式先解决输入顺序、动态尺寸、裁剪、量化/FP16、非线性和输出语义，不套用分镜 arena 偏移。
本版本 `IESNN::Net::CreateNetFromFile` 只分配空对象，非空返回不能作为模型加载证明。

## 5. 统一独立推理

`infer.py` 接收一个模型包、命名 float32 NPZ 输入，输出 NPZ 张量及带 SHA、shape、CPU 耗时的 JSON。
推理不会重新读取原始 `.model` / `.bytenn`、层表或厂商动态库；仍依赖本目录的 Python 模型实现。
它不是独立可执行文件，也不是 `torch.jit` 模型。

```bash
/opt/homebrew/bin/python3 research/local-model-pytorch/infer.py \
  --model .local/jianying-model-pytorch/tflite/model.pt \
  --input .local/jianying-model-pytorch/portable-inference/tflite-input.npz \
  --out .local/jianying-model-pytorch/portable-inference/tflite.npz \
  --warmup 1 --repeats 3
```

| 包 | NPZ 输入 | NPZ 输出 |
| --- | --- | --- |
| Espresso | 图中声明的所有命名 NCHW 输入 | 图声明的命名输出 |
| 新分镜 | `frames: [7,3,96,96]` | `features`, `probability` |
| 旧分镜 | `frames: [11,3,128,128]` | `features`, `probability` |
| TFLite | `image: [1,256,256,3]` | `logits: [1,256,256,6]` |
| 降噪原始图 | `data0`, `data1`, `data2`，均 `[1,3,1088,1920]` | `Add_38`，相同 shape |
| 人脸拟合子网 | `data: [1,212]` | `Mul_9: [1,442]` |

已实际运行以上八个模型包。拒绝未知格式、非有限数值、空输入/输出、错误 shape 和覆盖源文件。
单次本机耗时只用于探针诊断；并行任务负载不同，不据此承诺性能优于原生。
