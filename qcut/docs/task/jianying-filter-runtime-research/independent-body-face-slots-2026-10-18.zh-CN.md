# 美体视频：多个成功脸槽与原生重复合并

这是“保留旧脸恢复分支”的后续，覆盖固定版本原生的五槽分配、恢复检测、重复删除和对外输出顺序。独立实现从原始 RGBA 计算检测框和关键点；原生捕获只作为对照，未作为自研推理输入。美体骨架仍是单人跟踪，这项工作不等于多人身体同时变形。

## 按原生还原的状态机

- 五个固定物理槽分别保存 alignment、tracking、Base、roll 历史、ID、年龄和有效状态。原生容量为 5；当前配置不启用候选排序，因此检测超过 5 个时按原顺序只处理前 5 个。
- 冷启动按检测索引放入对应槽，拒绝的候选可以留下空洞。保留旧脸的检测先独立匹配每个有效槽，再把未匹配候选放进第一个空槽。匹配结果在新增脸之前一次计算，不把新脸追加回匹配表。
- ID 从 0 单调递增，在 160 模型通过后消耗；随后 120 被拒绝也不能回收这个 ID。初始化年龄为 1，每次成功的 120 跟踪再加 1。
- 普通模式任意一个槽跟踪失败，均触发同帧恢复检测，包括其他槽仍成功的情况。已有恢复窗口中再次失败不重新计时。窗口退出用去重后的有效槽数判断：只要比帧开始的脸数增加就退出，或在计数 30 的帧尾退出。
- 普通跟踪每 24 个原生帧补检。成功补检中新脸只做 160，标记为 `new`；下一帧 120 成功后才对外发布。恢复检测的新脸在同帧完成 160 和 120。
- 完全无脸且不在恢复窗口时，全局帧计数分别按 2／4／8 帧间隔检测（无脸计数小于 10、小于 30、至少 30）。当前配置不启用交替检测器。
- 公共结果剔除 `new` 槽，按脸 ID 升序输出。不能直接输出物理槽顺序，否则槽位复用后会改变美体头部选择的数组索引。
- 美体导出接口保持原来的预热契约：首张图先进行原生帧 0 的 160 初始化，再进行同图原生帧 1 的 120 跟踪。新增 `seed_only` 仅用于正确拆分这两个阶段及周期补检，不改变其他 alignment 调用的默认行为。

## `FilterDup` 三轮规则

只比较 `active && !new` 的槽，按物理索引从小到大遍历：

1. IoU 严格大于 double `0.2` 时，删除置信度低的槽；同分保留索引小的槽。IoU 是含 `+1` 边界的原生计算，和检测匹配的 float32 `0.3` 门限不同。外层槽在内层循环中被删除后，原生仍继续用它比较后面的槽，此顺序已保留。
2. 前面的框严格包含后面的框，且后者任一尺寸严格小于前者一半，删除后面的槽。
3. 后面的框严格包含前面的框且满足相同尺寸条件，删除前面的槽并结束这一内层循环。

删除只清有效位，不混合两张脸的点、不复制赢家历史、不重置其他槽。重复合并在这里实际是删除重复槽，而不是取平均或启发式融合。

## 去重置信度的浮点顺序

去重使用 alignment 模型的分类置信度，而不是检测器的分数。原生按 float32 依次累加 `prob[0]` 和扩展类别，再做 `1 - combined`。原来 ONNX 的分类终端存在最多 `7.45e-7` 的概率差；门控和关键点可以相同，但临近同分时仍可能影响去重赢家。

本轮复用已有四通道 FMA 点积顺序，从模型的共享 128 维特征重新计算分类全连接，再执行 float32 最大值平移、标量 `expf`、依次累加和除法。权重从已校验的本地模型读取，增加特征输出只发生在内存。116 次真实原生调用的分类概率逐位相同；另用构造的三类／五类网络直接调用原生 CPU，20 组结果逐位相同。`probability_heads=True` 只在视频脸序列启用，其他 Stage1 调用的默认行为保持不变。

## 实现与检查点

- `body_video_face_sequence.py`：调度、槽位分配、ID、输出顺序。
- `body_face_slots.py`：单槽滤波与对齐历史。
- `body_face_duplicates.py`：三轮原生去重。
- `body_face_matching.py`：原生匹配框、IoU 和最近检测候选。
- `alignment_probability.py`、`alignment_infer.py`：按已验证的浮点运算顺序重算分类概率。
- `alignment_sequence.py`、`body_face_start.py`：160 单独初始化及延迟 120。
- `body_sequence_checkpoint.py`：v2 检查点按槽保存历史，不序列化模型句柄；恢复后重新接上共享模型。旧 v1 检查点明确拒绝，源码清单变更同时隔离磁盘缓存。

## 结论边界

当前目标是这套固定模型和配置的多脸槽状态机及重复删除。其他模型、旋转模式、排序开关、内部局部恢复开关、极端无效种子沿用旧变换矩阵的分支，均不能据此宣称已对齐。仍使用原有本地私有模型；本轮没有训练或替换权重，也没有上传模型、原生库、原始反编译或图像。
