# 美体缺体帧、原生视频配置与参数事件（2026-10-19）

后续更新：[原生跳时与 RESET_PARAMS 完整重置](independent-body-reset-2026-10-19.zh-CN.md) 已补上本文末尾的运行中重置分支，并将检查点升级为 v4。本文测试数字与源码摘要保留为该阶段记录。

本轮关闭的是**单人、正向画幅、固定 CPU 感知、空保护遮罩**下的缺体帧与复合美体时序缺口。独立实现从原图自行推理，不读取原生捕获作为输入；随后再与锁定版本的原生完整效果图比较。48 帧受控序列的最终 1080×1920 RGBA 全部逐字节一致，最大差 0。它不代表所有剪映美体场景均已还原。

## 修复的实际差异

1. **没有身体结果仍推进状态。** 非空算法结果中人体数量为 0 时，原生仍更新描述符、强度、网格缓存并渲染。Status 保留旧关节历史，各部位按自身规则衰减；原先直接返回原图并冻结 composition 的实现不正确。现只在实际网格为恒等时跳过绘制。空人体向量与“有一个人体但所有关节均不可见”分开处理。
2. **缺体时仍处理脸。** 没有身体时尝试脸槽 0；有身体时按头部关节匹配。候选索引变化会清掉旧脸历史。没有脸的 `None` 与空数组都执行该选择过程；旧索引为 0 与旧索引为 1 的行为不同，已有专门回归。
3. **使用实际效果包配置。** 视频入口使用 60 列 × 75 行网格（4,636 顶点、9,000 三角形）。首帧 component input type 为 1；后续帧间隔大于 0.01 秒时为 0，否则为 2，按原 Lua 的双精度阈值比较。mode2 保留部分锚点，三项位移历史在实际执行时直接使用当前位移；未执行的部位不提前重置历史。旧局部 oracle 的固定 mode2／30×30 配置保留为另一种显式研究配置，不再作为生产视频默认。input type 与每个 item 的 strategy 是不同字段，不能由名称猜枚举值。
4. **补全初始化与描述符输入。** 原生系统在构造后调用 hard reset，腿部四个历史值因此由 0 变为 -1。长腿还读取腰部有效性、中心 Y 和身体尺度以决定保留锚点，下半段几何倍率为构造器的 0.3。肩／髋可靠度决定身体轴的混合权重，原先固定 0.25 只覆盖部分输入。
5. **补全三项位移历史。** 小头、美胯、瘦手臂在当前包中开启位移历史，degree 为 float32 0.2。权重根据新旧位移差的 L1 总量及画幅计算，首次直接保存；后续按原生浮点顺序混合并移除平方长度小于 0.001 的位移。身体消失时是否推进由各自的原生调用门控决定。两侧手臂共享这一层历史，肩部使用另外的缓存规则。
6. **按原生顺序采样。** 当前完整宿主使用 float 纹理采样，在片元阶段计算 `1 - v`。提前翻转输入图片行虽几何等价，插值舍入仍会不同。视频现在传入原始行序，在片元阶段翻转 UV；照片与算法图已有采样配置保持各自的契约。

## 参数变化不是单纯替换 target

原效果包的一个有效滑杆事件会让 Lua `updateItems` 重写全部十个 item；即使值相同，原生 setter 也会设置 dirty。下一次配置拷贝会重置全部强度步长，并标记三项位移历史在下次有效执行时重新初始化。历史在该部位未执行时仍保留；不能提前清空。肩部缓存不因一次同值事件一并重置。

`BodySmartSequence` 对实际控制值变化执行该规则，连续帧传入相同控制值不会重复触发。显式的同值赋值事件可通过 Python 会话 API 的 `reapply_controls=True` 表达。最后一次控制值、待处理配置和位移历史 dirty 标志都随检查点保存。该参数目前是会话 API 的事件边界，不声称完整编辑器 UI 事件传输均已对拍。

新版检查点升级为 v3：旧 v2 使用另一种网格与 composition 配置，不能直接覆盖新版状态。恢复入口在加载模型或修改会话前拒绝旧版本，要求从源帧重放；编辑器常规磁盘缓存仍按引擎摘要隔离。新版本内部的缺体、控制事件 pending-dirty、重新入画及检查点恢复均有逐帧回归。

已记录的新版活动快照约 244–250 KB，旧配置约 50 KB，增长来自网格与三项位移历史。该测量不等于长视频内存验收，已有渲染耗时也不是受控性能对比。

## 尚未完成

生产身体跟踪仍以单人为验收范围；初检多人体、交叉遮挡和身份选择、旋转与非零朝向、保护／分割遮罩、默认 CoreML 与其他平台、完整宿主启动及 UI 事件传输需要另行验证。手动美体的剩余采样差距也不由本轮智能美体结论覆盖。此次没有重新宣称长视频性能、音画同步或实时 24／30 fps 达标。

本轮像素结论来自引擎与原生效果图的逐帧对照，另有桌面会话／worker 回归；没有重新执行完整编辑器预览／导出 E2E，不能把引擎对拍等同于整套产品验收。

本阶段结束时，连续会话仅接受实际时间差 `(0, 0.1]`；运行中的完整 reset、跳时和 `RESET_PARAMS` 尚待还原。该缺口已由[后续原生重置工作](independent-body-reset-2026-10-19.zh-CN.md)关闭：按双精度绝对时间差选择原生模式，保留 warm 状态中的指定字段；名义 10 fps 跨越实际阈值也按原生规则处理。

独立路径已自行执行推理、状态、几何和 Metal 渲染，但仍使用从原版提取／转换的私有模型权重。**完全不依赖剪映来源文件的最终目标尚未完成**；格式转换不改变权重来源。本轮默认私有资产清单保持 363 项、72,827,136 字节，未新增或上传任何模型。
