## 01：本轮必须交付的可复核结果

5. **精确判定。** 对已固定的二进制及平台条件，返回值和输出槽要求逐项完全一致；至少两个独立进程重复。未知平台条件应显式留空或拒绝，不能悄悄当作当前系统。
